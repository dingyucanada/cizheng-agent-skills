# 公开教学图

Met 馆藏18.61.4的两幅公开整体图，网页标为Public Domain，馆方Open Access政策按CC0提供。来源和文件哈希见sources.json。下载文件未改像素，仍不等于相机原文件。馆藏记载是可查资料，不是本项目独立鉴定结果。

用于工作台操作及工具演示；没有打包任何模拟研判、黄金答案或专家盲测成绩。不得将同一器物的两张图算成两个独立器物，或将本器物作为自身的归属证明。

本地导入：`python -m cizheng.demo`；保留历史案卷，不覆盖已有资料。

manifest.json 可直接执行 paired_eval 默认准备（0调用）。加 --run 后仍只能作为已知身份、空参照库的功能检查，不纳入专业盲评成绩。
