# 修订与审查回应

先区分新原始图片、资料归属变化、操作人的订正和文字模型的疑点。各自来源不能混为一种“事实”。读取 review_dependencies 的变化清单并重新观察所有器物图；引用新的 observation_id。

对于 text_critic.result.issues，每项形成 accept、reject 或 unresolved：采纳须有当前图像或资料支持；驳回须指出冲突依据；尚不能确认须说明限制。调用 respond_critic 保存完整回应后再记录意见。

revision_explanation 应指出哪个旧解释得到支持、被削弱或仍未解决，以及新增依据。多个维度分别处理；不强迫制造一个“结论已经改变”的故事。

参照许可变化、图像更新或方法版本改变后重新建立运行。旧专家复核不覆盖新版本。完成初判及两轮补证后，仍不能支持归属则停止自动追问，交专家继续处理。

文字回应只能在主 Agent 的后续动作轮实际接收到本轮器物图像后调用。不要在 inspect_images 同一预定动作批次内先决定回应。每次最多4帧；超过4张图时分批查看并让主 Agent 在各次动作轮接收，最后再回应。
