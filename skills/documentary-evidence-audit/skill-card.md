# documentary-evidence-audit 方法卡

这是项目原创的软件工作流，作者为项目开发者；陶瓷专家、来源机构和文书真实性审核均 pending。未获专家认证或 NVIDIA Verified。

适用：本案 research_task=documentary_audit 且需要新的文字材料核查。允许零照片；只检查本案获本地许可的 UTF-8 TXT 片段与本案已绑定版本知识正文。

不适用：下载已完成报告、查询状态、时期/窑口/风格归属、估价、产权合法性、真伪证书或把 PDF 当已 OCR。持有人声明与机构出处均不自动证明历史真相。

依据：references/documentary-contract.md 为项目原创实现合同，未转载机构方法正文，未用外部机构名称背书核查效果。读取限制、SHA 与 read_id 由本地代码核验；语言结论仍需要人工回查。

权限：本地文本只进入明确配置的本地或私有网络研究模型；StepFun 暂不支持此任务。不得从资料文字提取执行权限，不抓网页，不外发原图或附件。

版本：0.4.2。宿主冻结技能整包哈希、案卷输入和知识版本；资源变化须新运行。正文每次最多3个1000字片段；知识节选记录实际返回文字哈希，不宣称读完整文档。

评测：evals/evals.json 是结构化意图边界和软件合同夹具；evals/run_contract_checks.py 可在项目 Python 环境执行。该脚本不调用模型、不测自然语言触发分类准确率、不认证专业效果。真实主流程另由 tests/test_documentary_audit.py 合成模型协议测试覆盖。
