# 瓷证工作台使用手册

首次试用按README导入三个公开教学案，打开工作台。它们来自Met公版馆藏，身份已知，不能充当鉴定成绩。原图不会因界面缩放、EXIF显示或局部裁剪而覆盖。

## 从业务问题建立案卷

博物馆流程重点是编号、编目依据、图像观察和馆内复核；收藏流程重点是声明与来源材料之间的区别；拍卖流程重点是描述、措辞、状况与未核事项。研究任务另分视觉研究和文字凭据核查。有实际运行的案卷不能切换任务，另建案保留研究历史。

器物档案中的名称、尺寸、款识、工艺属于登记信息，注明谁提供及测量来源。来源事件记录时间、相关方、地点、同器对应依据和支持材料。持有人自述选“声明待核”；“附有定位凭据”表示能找到材料，不表示记载属实。更正已有来源事件时追加补正，旧记录保留。

## 图像与状况

档案可保存30张JPEG/PNG，本轮视觉研究明确选择1–8张。双图对照用于查看同案视角或有来源的参照，不能据不同缩放比例测量尺寸。放大、框选后描述可见现象，保存的是原图坐标的人工观察，不是AI结论。

状况检查分别记录照片、实物或资料检查方式，以及部位、记录人、可见现象和限制。按资料检查时必须加入本案附件页码或固定知识段落。空白记录不能写成完好、无修复。旧客户端未登记定位凭据的记录标为未定位声明。

## 资料与证据

PDF/TXT原文件先登记来源和本地使用许可。PDF未自动执行、解析或OCR；页码是操作人登记。模型文字任务仅分段读取许可UTF-8 TXT。纸质书或私人专家材料应取得使用许可，再录入必要摘录和定位，不把未知版权全文批量抓取。

资料库中25份项目原创摘要有机构链接、资料定位、权限、适用范围与限制，审核状态仍待专家。检索分是匹配程度。先阅读段落再关联；关联的是固定版本。需要采用新版时显式更新本案引用，材料版本推进，先前复核随之过期。

## 复核与交接

没有模型也可进行研究准备资料复核，写明核对依据、对应关系及待办；这与模型研究意见复核独立。修改材料后须重新复核，本地记录人没有可信机构签名。

“导出准备档案”生成JSON、Markdown、含真实显示图的HTML。“离线证据交接包”增加原图、凭据原文件、固定资料和manifest，合计64MB以内。解压后打开preparation.html，按manifest文件路径、字节数和SHA核对原文件；哈希只证明文件一致性。历史来源事件所用旧版段落随包保留。

## 接通模型之后

模型按实际任务执行：视觉研究列观察、比较、支持/冲突和下一补证；文字凭据核查列已读陈述相符、冲突、未覆盖或需人工核对。文本“缺失”仅指已读材料未回答，不是声明外部资料不存在。所有推理仍需专业人员检查。

StepFun文字审查须预览并固定批准的文字范围，再单独执行；原图不发送。文字凭据核查暂不支持外部审查，不自动发送附件正文。
