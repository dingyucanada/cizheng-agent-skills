# 免上传公开体验与本地工作台

公开入口面向首次接触瓷证的访客和评审。材料已准备好，不需要先寻找器物照片、编写题目或导入资料；从一个业务问题开始，走到证据定位、补证比较、人工复核备注与导出。

图像是馆方公开 JPEG，不是相机原始文件，拍摄及处理历史未知。尺寸等数据属于馆藏记载，不是本项目重新测量。文件原字节与 SHA256 来源记录位于 `examples/public-demo/`；馆方 [Open Access 政策](https://www.metmuseum.org/policies/image-resources) 与具体来源说明一同保留。

教学案卷同时准备项目原创文字说明、资料摘录定位、人工编写的观察和研究示例。它们的作用是让访客操作完整流程，均不冒充真实模型输出、机构审定意见或专家样本。身份已知的馆藏对象不是独立鉴定盲测。

## 访客实际做什么

1. **选案与读材料。** 查看任务、馆藏身份、照片、来源和当前缺口，不上传私人图片。
2. **编辑记录。** 补充器物登记、个人观察与备注，区分来源记载和自己的判断。
3. **回查证据。** 从观察定位照片区域，从资料卡回到具体文字和出处；阅读采用的实际 Skill 方法。
4. **补证与比较。** 查看预置的第二视图或文字凭据，比较教学研究示例的两个版本，记录哪项依据改变、哪项仍不足。
5. **人工复核备注。** 保存自己的复核选择与说明，材料编辑后需要重新核对。浏览器操作者身份未经认证。
6. **导出。** 生成当前记录的结构化 JSON、可读报告或证据交接包，文件清单和哈希便于回查；标识保留教学来源及未调用模型状态。

文字与状态保存在当前浏览器的本地存储。更换设备、清理站点数据或使用另一个浏览器，不保证保留操作；要留存请导出。重置只恢复该教学案的浏览器记录。请勿把浏览器操作当成机构多用户记录、专业签名或不可篡改审计。

## 教学示例不等于实时 AI

公开体验固定显示“教学导览”状态。预写意见不使用 AI 生成动画、假进度、真假概率或伪造工具日志。公开体验不会调用 Spark、StepFun 或第三方推理接口，不会把访客输入发去云模型。访问网页和公开图片本身仍由 GitHub Pages 提供。

公开体验展示可执行的产品交互与研究方法；实时 Agent 必须在本地 / Spark 服务连接后，实际发送所选材料，读取工具回执、记录使用量并产生新运行。后续如发布真实公开推理回放，须清楚标明“历史回放”、运行时间、模型版本、输入及工具记录，不能说访客当前触发了同一模型。

## 与本地专业服务的分工

| 能力 | GitHub Pages 教学体验 | 本地 / Spark 专业工作台 |
|---|---|---|
| 现成公开案卷 | 三套，无需上传 | 可一次导入完整教学案，也可建立自己的案例 |
| 私人原图及附件 | 不接受私人原件上传 | 保存本案原字节、来源和权限；UTF-8 TXT 可读，PDF 当前不 OCR |
| 资料 | 随教学案打包的公开 / 项目原创内容 | SQLite 来源版本库、固定本案资料版本与实际段落读取 |
| 研究意见 | 项目编写的教学示例，始终注明来源 | 真实模型成功运行产生；无端点时明确不可运行 |
| 复核 | 本浏览器备注，身份未认证 | 材料复核与模型意见复核分别绑定版本，仍未具备可信机构签署 |
| 数据位置 | 浏览器本地修改；静态公开材料由 GitHub Pages 提供 | 指定本机 / Spark 数据目录；取决于实际部署，不笼统声称原图只在盒子里 |
| StepFun | 不请求云模型 | 只审查公开或明确批准脱敏的文字，先预览批准，不发送原图、不自动重试 |
| 交接 | 教学文件、当前编辑和清单 | 本案原件、文书和被引用固定资料，不打包全库或其它案件 |

GitHub Pages 是静态托管，不能执行 Python 后端。不要把访问 Pages 与访问实际 Spark 模型混为一谈。要体验真实资料工作和连接模型，请使用 README 的本地启动方式与 [Spark 验收说明](spark-validation.md)。

## 专家与评审怎样继续验证

页面可以帮助检查材料是否易读、证据是否能定位、流程是否完整。真实专业质量需要专家提供有许可的独立器物资料，指出容易误判的地方，再用实际模型验证。公开馆藏的已知标签、清晰截图、文件哈希和完整流程均不能替代这一步。
