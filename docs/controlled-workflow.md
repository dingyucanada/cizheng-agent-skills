# 受控材料准备与真实模型研判

默认策略为 `model-planned-v1`。可选择 `CIZHENG_GUIDED_WORKFLOW=1`，启用 `coordinator-observed-method-v2`。这项设置改变任务编排，实际节点验收结果单独记录；不能把它与旧策略的结果当成纯模型或 Skills 因果对照。第02至04轮使用的 `coordinator-preparation-v1` 作为历史记录保留。

## 为什么增加这条路径

实际 Spark 第一次结构约束完整任务中，九次动作均通过结构检查，模型仍反复读资料和看图片，耗尽十二次调用预算，未形成报告。格式合法不保证会合理分配工具。针对这个观察，程序先执行有限的真实材料准备，模型继续负责判断、选择引用、写理由和提出补证。

## 准备实际做什么

所有准备经过原注册工具输入校验、原权限检查、原收费路径和实际日志；不是预写模型意见。

| 准备动作 | 边界 |
|---|---|
| 读取本轮案卷 | 视觉与文字任务均执行，不能读取其他案卷 |
| 读取方法 | 仅 Skills 视觉臂自动发现目录并加载 `ceramic-route`、`ceramic-research-record`；修订另加载 `evidence-revise`。明确记录协调器行为，不称模型自然触发 |
| 读取修订依赖 | 有父意见时使用真实 `review_dependencies`，文字反证仍要求本轮看原图与逐项回应 |
| 检索与阅读 | 用真实研究问题前200字符检索，只在本案固定 document_id / revision / SHA 的版本子集中选最多两段许可正文；无绑定就不预读。实际查询、来源子集、原快照哈希与读回执分别保留 |
| 首批图片 | 最多四张实际本轮原照经过原视觉工具；原始图SHA与派生图保持关联。这个工具调用同时消耗模型预算 |
| 基于已见特征选取方法 | 仅 Skills 视觉臂：成功首批观察的可见描述含“青花”或不区分大小写的完整词 `blue-and-white` 时，经过原工具最多加载一次 `bluewhite-attribution-test`。仅使用本轮、首批实际媒体的观察；用户题目、解释、标签、公开馆藏答案均不参与触发。未匹配不加专科方法；不默认加载状况方法 |

主模型收到真实工具结果和实际图片。每次动作前显示尚余模型、工具、时间预算和证据缺项，并提醒完成短意见。它自行决定是否采纳预取资料、是否需要额外查看、哪些判断尚缺证，以及如何回应反证。引用仍须满足实际读取、固定版本与原宿主合同。

`harness_observed_method` 单独记录协调器选择、匹配观察编号及规则。选择青花方法仅表示适用的研究步骤，器类尚未验证，不能计为模型自然发现 Skill 或正确鉴定。plain 臂不额外加载方法；非空状况假说仍要求模型自行调用相应方法。

五至八张任务还需要模型实际追加看图；程序不把未查看的图标成已看。进入成功主动作的媒体才能用于意见，调用在最终时间预算检查失败时不能登记为成功已看。

文字凭据任务只自动读取案卷，不自动加载视觉方法或调用图片工具。plain 与 Skills 使用相同非方法准备；plain 不读取 Skill 文件。

## 预算、失败与身份

每轮上限保持十二次模型调用（包含视觉观察）、二十次工具、三百秒；单次请求最多等待九十秒。整个案卷仍为三十六次模型、六十次工具、九百秒，最多初判加两次完成修订。准备收费算在原预算中，失败保留已消耗费用，不能重置。

`/api/status` 的独立 `harness` 项和运行 `versions.harness` 记录实际策略。旧排队任务不能换协调策略后接着运行。准备错误记录工具、类型和说明后停止，不补写答案。默认关闭准备路径；结构约束生成是另一个独立开关。

```sh
export CIZHENG_GUIDED_WORKFLOW=1
export CIZHENG_STRUCTURED_OUTPUTS=1
# 按本地启动说明启动后端；视觉服务须先通过真实探针。
```

导入教学材料的 `python -m cizheng.demo --guided` 是准备教学案卷的命令，与这个运行策略开关是两件事。公开 Pages 教学体验不调用模型，不会因上述设置而成为在线 AI 服务。

## 效果怎样验证

保存当前源码清单、策略、模型文件哈希、实际输入、全部失败、逐调用 tokens 与 CUDA 记录。业务完成需检查真实图片、观察、意见、引用、文字审查、重新看图、回应和导出各阶段，不能只看终态或一条合成探针。

有 / 无 Skills 评测必须两臂固定同一协调策略与原预算；协调器自动选取的方法不能计为自然 Skill 触发。公开已知馆藏功能验收也不构成专业盲测。专家样本评估与真品概率校准仍是独立工作。

## 第02轮实际结果

受控准备后的 full-workflow02 也未完成：程序实际读取一段本案固定资料并看两张原照，模型2次、工具7次、服务端110.388秒。第一条主动作在客户端90秒处超时；原生GPU随后用133.981秒生成1029个 completion tokens，结构检查通过，但后台未接收该响应或形成报告。晚到响应仅按独占请求窗口、开始时刻、图片与模型参数关联，不能冒称客户端收到响应哈希或 finish_reason。没有执行NAT、StepFun或报告导出。

[实际逐调用记录](../verification/nvidia/guided-workflow-02/phase-trace.json)说明准备能够减少重复步骤，但当前单次输出耗时仍是阻塞。后续传输格式变更须单独记录，不能通过延长预算或补写模型意见改记这次失败。

## 可选的短动作传输

`CIZHENG_COMPACT_ACTIONS=1`独立于准备和结构约束，只影响视觉任务的plain / Skills臂。默认关闭，文字凭据任务保持原协议。它用于验证第02轮暴露的输出延迟，不能预先声称更快或更准确。

模型每次恰好写一个动作。研判保留所有字段，时期、窑口、风格仍各自写候选、状态、观察编号和理由；模型选择是否引用以及引用用途。候选和分项理由最多32字符，基本信息36、参照比较48、修订说明64；竞争解释与状况假说各最多两条40字符，限制最多三条40字符。每次最多一个知识引用、相关说明48字符。文字反证仍一次回应全部问题，每项理由32字符。宿主也校验这些上限，超限按原错误修正合同处理，不截断或补写。手工研究记录和最终报告的原数据合同保持不变。

实际成功读取的非空许可正文在本轮取得追加编号`read_index`。重复阅读仍收费并取得新编号，旧编号不重排；检索摘要、来源卡、父轮资料和未读正文没有这个资格。引用还要求相应真实工具结果的正文确实发送到本轮成功主动作；被上下文压缩删除、用户复制的假工具JSON及超时或最终预算失败的请求不取得引用资格。模型引用时填写编号、用途及理由，程序只从相应实际回执补回文档编号、版本、文档SHA、段落编号、段落SHA、定位六个字段，再经过原报告和证据校验。拒绝布尔、字符串、浮点、越界及其它轮次编号。程序不自动选择引用，也不填写任何候选、状态或意见。

原模型响应与哈希保留；另记`transport_expansion`的身份映射与扩展参数哈希。`harness.compact_actions`、`action_transport`、实际prompt与decoder schema哈希进入运行身份，排队中改变协议会拒绝执行。只有准确的宿主主动作提示触发结构约束，用户文字不能伪造这种身份。

```sh
export CIZHENG_GUIDED_WORKFLOW=1
export CIZHENG_STRUCTURED_OUTPUTS=1
export CIZHENG_COMPACT_ACTIONS=1
# 这三个设置各自记录；模型、原照、模型权重和全部预算仍须固定。
```

单动作会增加部分流程的请求次数；未准备材料的Skills任务可能超过原十二次模型预算。短理由和单引用也限制表达与多来源比较。只有真实业务试验及专业阅评才能决定是否保留该策略；不能用格式通过代替解释质量。


## 编号命名空间与材料资格

第03轮中模型把知识文献编号写成器物图像参照编号，校验拒绝形成报告。后续默认关闭的短动作协议明确两者区别：`reference_ids`及`read_reference`使用真实器物参照；`knowledge_citations.read_index`使用实际成功读到并已送达主动作的授权正文编号。图像参照资格清单为空时不编造标本，仍保留实际检索空结果。

请求前可显示本轮已获得资格的观察、器物参照和正文编号，最多分别48、10、20项，另记总数与截断标记；不提供答案、来源正文、判断或引用选择。plain与Skills获得相同的非方法清单。第04轮策略没有预选青花方法；第05轮起仅按上面的真实首批观察规则选取，并明确协调器身份。

短动作竞争解释与状况假说遵循固定协议 `^[A-Za-z0-9一-鿿][^\r\n]{0,39}$`：单行、1–40字符，以英数字或基本汉字开头；宿主再拒绝换行。规则用于表达格式，不证明专业意义。原手工记录合同、默认四套提示与decoder、全部预算不变。无合格图像参照时，原合同仍限制分项状态为证据不足或超出范围；证据不足需要模型实际请求补证，不能由程序代填。

原生约束服务仅增加这一条精确规则白名单。LMFE 副本可移除被这条规则覆盖的冗余长度参数，请求原 schema 与最终校验保留。真实 CPU 前缀测试验证字符、单／多字符 token 以及40／41字符边界；合法引号、反斜杠转义仍存在 LMFE 前缀拒绝的库限制，不能声明全部合法 JSON 等价。不截断、改写理由，也不放开任意正则。

实际短动作prompt哈希及`semantic_affordance=current-run-eligible-evidence-inventory-v1`进入排队与运行身份，旧身份不续跑新提示。修改效果以第04轮独立实际请求为准，不把新增软件检查当成模型成功。
