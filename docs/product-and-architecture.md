# 瓷证：产品与系统架构

## 产品主张

给专业人员一张能回到原图、原文件和资料段落的研究桌。核心成果是可继续工作的证据案卷，而不是照片真伪打分。博物馆、收藏和拍卖入口调整材料重点；视觉研究和文字凭据核查决定工具权限及输出合同。

本地可完成器物登记、来源事件、原文件保存、状况检查、区域观察、固定资料关联、材料复核与离线交接。模型仅在端点实际可用时执行。Spark未连接、专家样本未验收时，这些材料工作仍可真实使用。

## 前后端与数据

前端无外部CDN，使用三栏研究布局、真实图像双图/缩放/选区、来源卡与固定段落、核查矩阵、补证和复核。后端FastAPI；SQLite保存案卷、原始blob、运行记录和幂等请求，知识库另保存不可变版本与关键词索引。

| 对象 | 固定关系 | 变化后行为 |
|---|---|---|
| 原图/附件 | 文件SHA、来源、许可、原字节 | 新材料推进案卷；原件不覆盖 |
| 人工记录 | 日期、方式、区域或资料locator | 追加事件/补正保留历史 |
| 知识引用 | 文档版本、文档SHA、段落SHA | 更新知识库不改旧案；显式关联才更新 |
| 材料复核 | 案卷版本及单独复核版本 | 材料变化后显示过期 |
| Agent运行 | 冻结案卷、所选图、工具/提示/Skills版本 | 补证后新运行，失败成本保留 |
| 离线交接 | 本案原件及当前/历史被引用段落 | 不含全库、其它案卷或凭据配置 |

API仅监听本机回环，会话令牌保护写入，不跨站写入。源码包不带私人数据库、密钥或模型权重。机构多用户授权、可信专家签署、审计合规与灾备尚未完成，本版适合受控专业试用。

## Agent Skills 与 Harness

Skills是可迁移方法包，NVIDIA提供生态和Verified流程，不等于每个业务包天然经过NVIDIA认证。项目有7个自研包，按描述发现、读取正文和按需资源；每个包记录依赖、适用/排除、责任、专家审核及效果限制。

Harness注册有限工具，约束输入输出、来源权限、实际读回执、预算和版本。视觉意见要求原图实际进入成功主动作、观察ID可定位、引用确实读过；文字任务不开放看图工具或年代归属结构，只允许引用本轮实际读到并送入成功主动作的文字。UTF-8 TXT分段读取，PDF不OCR。长登记和历史分页回查，避免把所有案卷记录一次挤进模型上下文。

单轮最多12次主模型、20次工具、300秒；整个初轮与修订共享累计36次模型、60次工具、900秒。取消和失败仍保留用量；没有真实端点就不制造替代结果。资料内容里的指令不具有执行权限。

## RAG与专家方法

25份原创短摘要提供起步参照，分馆藏个案、术语、状况和来源方法。关键词检索后实际读段落，保留作者、原机构、locator、权利、适用范围和局限。馆藏标签只指该馆藏，不能转成待鉴器物真值。后续专家材料须有许可、明确对象与依据、难例和独立验收；专家审核不能由脚本假定。

Jev是浏览器任务方向，Laya在此仅保留可关闭的文本影子实验；二者都没有陶瓷视觉预审训练/校准证据。核心链路用可验证文件检查与任务合同，未宣称能概率识别AI图或真伪。无需为双模型叙事而增加未经验证的预审器。

## 平台接入与证据不足

视觉原图预留本机/私网Spark；StepFun仅接批准公开或脱敏文字。已有Spark部署配方与端点探针，尚未实测。工程、合成工具协议与浏览器测试验证系统合同；真正的专业收益须同模型同预算有/无Skills、独立专家样本及复核结果证明。当前没有这些成绩，不把模型公开榜单当陶瓷效果。
