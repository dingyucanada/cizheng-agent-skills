## 建议作品视频：约三分钟

这是项目建议叙事，不是官方规定时长。可先拍实际材料准备，再补录真实模型片段；教学示例在视频上保留清楚标识。

1. **业务问题，20 秒。** 从公开完整案卷开始：照片和来源资料已在，说明“风格相似为何还不能证明制作时期”“图录措辞为什么需要凭据”。展示对象、问题和使用角色。
2. **证据桌，35 秒。** 点击一条观察定位原图区域，双图查看，回到实际资料段落及固定版本。展示本人补充记录，而不是用装饰性热点声称模型发现。
3. **真实 Agent，45 秒。** Spark 接通后，实际运行日志展示任务路由、所需 Skill 加载、工具读取和引用。列出支持、冲突、不足和下一项补证；日志只展示可公开数据。
4. **补证与审查，35 秒。** 加入一项确实存在的新照片或资料，比较前后主张。若使用 StepFun，展示批准的公开 / 脱敏文字包、单次审查及主 Agent 响应；明确审查模型未看原图。
5. **可核查收益，25 秒。** 展示实际 Spark 环境 / 耗时、同模型有 / 无 Skills 个案、专家检查的分母。无改善和失败例保留；未测指标不显示数值。
6. **交付，20 秒。** 人工复核，导出案卷和证据 ZIP；打开报告、核对文件清单，说明尚需实物或专业检查的部分。

录制来自真实操作。等待可以剪辑并注明，不能把教学固定意见、脚本模型或纯色图测试剪成真实推理。模型现已连接，真实GPU生成与失败过程可以如实录制；在完整任务成功前，不能将固定教学意见剪成真实模型报告。

## 接到 Spark 与 StepFun 后的收尾顺序

1. 按 [Spark 验收](spark-validation.md) 检查环境并优先复用健康服务，固定模型和镜像版本。
2. 跑模型协议探针，再跑公开教学案完整链路；探针不是陶瓷能力测试。
3. 取得专家样本许可，隔离答案和模型，同模型、同资料、同预算比较有 / 无 Skills；保存失败与专家意见。
4. 用公开或明确获准脱敏文字完成 StepFun 预览、批准和实际单次审查，检查原图未外发。
5. 更新公开文档与演示材料；不公开私人样本、密钥、内部路径或未授权培训 PDF。
6. 录制和发布真实视频 / 文章，取得团队合影，再按当前官方表单完成提交。

旧版本和开发过程可以保留作记录；表单、主页和 README 必须指向同一个最终仓库和实际演示版本，避免混投历史开发包。
