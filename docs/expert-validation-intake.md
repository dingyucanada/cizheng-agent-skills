# 专家样本接入与验证

专家与拍卖行、博物馆提供的样本目前在另一台电脑上。当前版本尚未用这些材料完成专家验证，也没有估计真品概率。网页内置案例用于演示工作流程，不能代替验证集。

## 转移时需要的最小资料

每件器物建立一个目录，保留原图，按整体、底足、口沿、纹饰、款识、损伤等视角命名。不必为演示补造不存在的照片。

把材料分为两包。证据包包含样本编号、资料提供机构、使用范围、业务问题、尺寸、拍摄条件，以及已知的修复或后配记录；未知就写未知。专家标签包单独保存专家认可的年代与窑口、不确定范围、支持依据和容易误判的部位，首轮不送入模型、RAG 或 Skill。标签包供报告生成后的盲评核对，不能作为模型已知答案。价格与所有者个人信息不属于模型分析必需资料。

## 验证顺序

1. 冻结输入、专家说明和版本，生成文件哈希。标记图片是否属于同一器物，不把同一件器物的不同照片拆分到训练与测试两侧。
2. 第一轮只向系统提供照片及业务问题，隐藏专家结论。记录模型、Skill、知识库、用时、失败与补图要求。
3. 专家分别检查图像观察、区域定位、资料引用、判断理由与拒绝判断的合理性。每条意见关联具体照片或引用，保留修改前后的报告。
4. 汇总观察错误、无依据推断、引用不支持结论、重要疑点遗漏，以及流程完成率和端到端耗时；少量样本逐件呈现，不宣称代表全行业准确率。
5. 修复后使用保留样本回归。已有测试结果与失败日志保持可追溯，不用更换样本掩盖退步。

## 评价表

| 字段 | 记录方式 |
| --- | --- |
| 图像观察 | 正确 / 部分正确 / 错误 / 图像无法判断；对应区域与原因 |
| 资料引用 | 来源可核对、原文实际送达、引用与本器物推断的支持程度分别评价 |
| 判断理由 | 观察到什么、依据是什么、替代解释是什么、尚缺什么 |
| 年代与窑口 | 专家参考结论及不确定范围，不以单一硬标签强迫评分 |
| 人工复核 | 是否应复核、需补拍或开展哪些实物检查 |
| 运行结果 | 完成 / 请求补图 / 失败；用时、模型调用与费用记录 |

原图继续由 Spark 处理。仅明确获准的公开或脱敏文字可交给 StepFun 审查，专家材料接入不会自动扩大现有外发范围。

## 真品率的边界

当前报告中的照片覆盖度与证据状态是工作流程指标，不是真品率。将来若要显示概率，需要定义所针对的器物群体、独立真伪标注、足够的真品及仿品、校准与外部分布测试，并公开误差与拒判条件。Jev、Laya 的模型概率不能直接转换为古陶瓷真品概率。
